# 🏥 Hospital Emergency Room Dashboard | Microsoft Excel

## 📌 Project Overview
An interactive Hospital Emergency Room Dashboard developed using Microsoft Excel, applying concepts and techniques learned through Satish Dhawale Sir's tutorial.

The dashboard presents key healthcare metrics and helps analyze emergency room performance through interactive visualizations.

## 📊 Project Features

### 1. Data Preparation & Analysis
- Organized and prepared healthcare data for analysis.
- Used IF functions to apply logical conditions and categorize data.
- Summarized patient information using Pivot Tables.

### 2. Dashboard Development
- Created Pivot Charts and visualizations to present patient statistics.
- Added interactive Slicers and a Timeline for filtering.
- Used hyperlinks for dashboard navigation.
- Applied Conditional Formatting and Data Bars to improve readability.
- Designed the dashboard layout and visual presentation.

### 3. Key Performance Indicators (KPIs)
- Total Patients
- Average Waiting Time
- Patient Satisfaction Score
- Admission and Non-Admission Status
- Age Group and Gender Distribution
- Patients Attended Within 30 Minutes
- Department Referral Analysis

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables and Pivot Charts
- IF Function
- Slicers and Timeline
- Conditional Formatting
- Data Visualization

This project strengthened my practical understanding of Excel-based data analysis, interactive dashboard development, KPI monitoring, and data presentation.
